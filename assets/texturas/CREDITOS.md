# Créditos de texturas

- `suelo`, `concreto`, `lamina`, `techo`: texturas CC0 de [Poly Haven](https://polyhaven.com)
  (concrete_floor_02, concrete_wall_008, corrugated_iron, rusty_metal_02), 1K, ajustadas a la paleta de la aldea
  con `tools/texturas_polyhaven.py`.
- Texturas `<modelo>_color.png` de edificios y objetos: generadas con Meshy (texto a 3D) para este proyecto.
- El resto: dibujadas por código (`tools/texturas.py`, `tools/emblemas.py`).
